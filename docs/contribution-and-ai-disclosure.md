# Contributions and AI-Assisted Implementation Disclosure

## Student developer contributions

The project owner, **S. Divya Darshan**, reports responsibility for:

- Identifying the assistive-navigation problem and proposing the smart-cane product concept.
- Building and assembling the physical prototype.
- Integrating the Raspberry Pi Pico, ultrasonic sensor, servo, vibration motors, transistor drivers, and buzzer.
- Testing the sensor, servo, buzzer, and vibration outputs during prototype development.
- Establishing the intended interaction logic: scan three directions, remain silent during normal scanning, lock on a close obstacle, and activate only the corresponding directional haptic output.
- Calibrating the servo command positions for the assembled cane.
- Preparing and presenting the product idea through the institution to the AICTE Indovation Centre process.

These statements describe the project owner's account of their work and should be updated if team members or institutional contributors need to be credited.

## AI-assisted work

AI assistance was used during development for tasks such as:

- Explaining component interfaces and transistor-based motor switching.
- Troubleshooting Arduino firmware and sensor behaviour.
- Helping structure and review the firmware logic.
- Drafting repository documentation, diagrams, test plans, and explanatory material.

AI-generated suggestions were reviewed and adapted as part of the development process. The physical assembly, hardware decisions, and prototype testing are not claimed as work performed by the AI.

## Code and documentation authorship

The repository contains a consolidated and formatted firmware version based on the project logic and code supplied during development. The repository documentation is AI-assisted and should be reviewed by the project owner before formal submission, publication, or technology transfer.

## Disclosure principle

The project is presented as a student-developed prototype with AI-assisted engineering and documentation support. No claim is made that AI independently designed, built, or validated the physical device.
